- (constraint) 单进程纯插件，禁止子进程/端口/跨进程锁文件，后台任务只用 ctx.timer；多一个部署单元就多一套生命周期，而宿主已有 timer。
- (constraint) 单文件库直连不设适配层，业务只经 store/ 具名函数访问；适配层会把图扩散、payloadFilter、快照校验削平成 CRUD。
- (constraint) 身份是 mem_key 业务键、节点 id 禁进导出/日志/配置；同一 mem_key 至多一条未失效由 (mem_key, active_slot) 唯一索引在数据库层强制。
- (constraint) 唯一写入口 + 全进程单写队列，一次业务写入一张补丁表一次 commitTransaction；三个入口（remember / 用户命令 / 去抖抽取）共用这一段。
- (constraint) 零物理删除：delete/unlink 的方法形态与事务 op 字面量都进 AST 门禁，仅三个具名豁免（快照目录/审计轮转/卸载前导出）。

- (constraint) 注入单出口：身份段 ≤1200 字符走 section()、状态尾巴 ≤30 token 走 context()，两处只在 prompt-composer；场景常驻 0；注入路径不查库。
- (constraint) 召回只读有界：5/8 条、三段 250+600+20ms、硬上限 1000ms 到点不返空；② 失败只降不空，只产分数，剪枝由阈值+top-k 确定性执行。
