要点：
1. #3 是本线唯一「现在不做以后做不了」的项。推导事实不存历史，事后补 rule_id/justification_id/depth 意味着全部历史推导无法溯源，而 data-model.md 现在只有 origin。
2. #1/#2/#4 是一组，必须一起做。单有三值没有证明树，#4 的缺口报告会退化成「证不出来」字符串；单有闸门没有三态，闸门给出的 support 无处消费。
3. #7 的正确定位是「替代点概率」，不是「加一层概率」。研究报告明确不要点概率（假精确），改用证据计数 + 读时投影；surprise 只该用来分配写入/巩固预算，不判真假（O:120–129）。
4. 明确不该进的：聚合/计数/排序/向量相似度进推理层（G:428，实测 8000 条聚合加载 30845ms）；预测式世界模型与「KG 即世界模型」（O:200–204，AriGraph 无转移函数）；SHACL 当唯一校验层；自研 Datalog 引擎（G:403–413）。另外 validAt(t)/knownAsOf(t) 时间旅行已在 data-model.md:11 落地，不重复立项。
5. #8 不是产品能力，是实现期硬约束。它应进 AD 与回归测试，若开成 epic 会挤掉真正的能力增量。

建议归属（子代理判断）：全部落在现有 Epic 3–7 的增量（#1/#3/#5/#7 → Epic 3；#6 → Epic 4 与 Epic 6；#2/#4 → Epic 5），不需要新 Epic 8+。理由是每条都能指到既有 FR 的语义扩张：三态与缺口是 FR-4/FR-14 的返回面，契约层准入是 FR-11/FR-12 的前置闸门，K1/K4 是 FR-22 写路径与 FR-8 固化的检查点；单独开 Epic 会把同一条召回管线切成两半，反而破坏 AD-8 的三段预算约束。
