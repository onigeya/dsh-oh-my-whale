- **rubric #1 的「SM-1 在 v1 末必须过线」**：只采纳一半——v1 只要求评测集与口径就绪，过线推到 v1.5。理由：单用户 dogfood，50 条样本在 v1 末不存在（真实数据不足），强行过线只会造假样本。

- **adversary F2 建议的「空闲触发」**：只采纳启动补跑，不采纳空闲触发。理由：空闲触发会在长会话中途插入固化，与「写事务 p95 ≤10ms」和「不占用下一轮首 token 之前路径」冲突；启动补跑已能覆盖桌面宿主的主要场景。
