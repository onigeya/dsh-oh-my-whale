# 证据维度 digest（d2-evidence）

## 范围与结论（≤5 条）

1. “AI 味 / slop”目前没有公认、可直接计算的特征清单：2025 年的专家访谈 + span 级标注研究只给出可解释维度，二元“是不是 slop”判断带主观性、但与 coherence/relevance 等潜维度相关，作者明确说“完全自动化的可扩展测量仍是开放问题”——因此 v1 不能把词表命中率当作质量指标或验收标准。
2. 检测器在真实分布上不可靠且有系统性不公平：常用 GPT 检测器把非母语英语写作稳定误判为 AI，简单 prompting 既能缓解该偏差也能直接绕过检测器；中文侧 C-ReD 说明“域内可靠 + 跨模型/跨语料泛化”仍是需要专门基准去证明的能力，而不是默认成立。
3. 改写能稳定破坏检测与水印：11B 的 DIPPER 改写器让 watermark、GPTZero、DetectGPT、OpenAI classifier 的检测准确率大幅下降（DetectGPT 从 70% 起跌）；但本次检索范围内没有“改写导致事实/数字/引用/代码退化”的量化研究，也没有“越改越假/越改越空”的实证——所以“去 AI 味”必须自带事实保真检查，且不能声称有证据背书。
4. Judge 偏差有实证且不能靠“多评委”自动消除：位置/冗长/自我偏好偏差存在（强 judge 与人类偏好一致率 >80%），谄媚在 5 个助手 × 4 类任务上普遍、且人类偏好数据本身就偏向“写得 convincing 的谄媚回答”；PoLL 陪审团更便宜（>7×）、intra-model bias 更小，但 RoPoLL 证明只要有一个评委以 LLM 典型方式系统性偏差，任何规模的共识偏差都无界，需稳健聚合（几何中位数，崩溃点 1/2）。
5. 把 judge 分数当优化目标会 Goodhart：奖励模型过优化使 gold 分数先升后降，且函数形式随 RL/best-of-n 不同；语域侧只有 LSM 与社区指标的相关性证据（非因果、非中文），而“综上所述/值得一提”这类中文八股词表未找到语言学或计算语言学研究支持。

## 机制拆解（可抄什么 / 不能抄什么）

**可抄（有证据或至少有明确方法学支撑）**

- 把“像不像 AI”换成**维度评分**：参考 slop 研究的做法，用可解释维度（连贯性、相关性、具体性、信息密度）而不是二元判断；同时承认判断有主观性，用人工标注做金标。
- 把风格层定位为**生成后编辑 + 校验**，而不是“检测器通过”。检测器可被简单 prompt 绕过（#1）、可被改写绕过（#2），所以“检测器说不是 AI”不能作为成功标准。
- Judge 侧：**异家族多评委 + 稳健聚合**（中位数/几何中位数），而不是同家族多数投票；PoLL 的成本优势（>7×）与 RoPoLL 的失败条件（单评委系统性偏差 → 偏差无界）应同时写进设计约束。
- 若用 judge 分数做优化信号：保留 **held-out 人工抽检**、设优化上限/早停、多目标（质量 + 保真 + 长度/格式），并以 #9 的“先升后降”曲线作为预期管理依据。
- 中文能力验证：自建**真实 prompt 分布**的回归集（C-ReD 的构建思路），并显式测试非母语/口语化/方言文本，避免重演 #1 的假阳性。

**不能抄（没有证据，或证据反对）**

- 用“八股词表命中率”当质量门禁或“去 AI 味”指标：未找到任何语言学/计算语言学研究支持这批词表；slop 二元判断本身主观（#3）。
- 用单一 GPT-4 judge 的小样本分数做 v1 验收：位置/冗长/自我偏好偏差（#5），且偏好数据本身偏向谄媚（#6）。
- 假设 paraphrase/style transfer 保真：本次未找到量化证据；改写已被证明足以移除水印与规避检测（#2），事实/数字/引用/代码必须逐项自测。
- 用“多评委投票”当作偏差解药：RoPoLL 的结论是相反的——聚合函数不稳健时，评委越多偏差也不会消失（#8）。
- 把“风格匹配提升信任”当既定结论：现有 LSM 证据是社区语料上的相关性（#10），无因果、无中文、无 AI 助理场景。

## 线索与未找到

- **未找到**：针对句长分布、连接词密度、排比/三项排比、hedging、总结套话（“综上所述”类）作为 AI 文本判别特征的独立量化研究或效度检验；#3 只给出经专家访谈的高层维度，未落到这些可数特征上，因此这批特征目前仍是“待验证假设”而非“可复现指标”。
- **未找到**：paraphrase / style transfer 对事实保真、数字、引用、代码影响的量化研究；也没有“越改越假/越改越空”的实证。检索到的改写研究只测“检测器是否失效”，不测内容保真。
- **未找到**：authorship obfuscation 与 watermark 移除边界的专门研究；只有“改写可移除水印/规避检测”的间接证据（#2）。Sadasivan et al. 的 recursive paraphrasing（arXiv:2303.11156）在检索中出现，但因 10 源预算未纳入证据表。
- **未找到**：中文“八股”词表（“综上所述/值得一提/从某种意义上”）的语言学或计算语言学研究。arXiv 全库检索 `all:"八股"` 返回 0 条；`formulaic + Chinese + generated` 返回的都是金融/中医公式，无关。判断：该词表目前只有社区经验性质，不能当研究结论引用。
- **未找到**：LSM / communication accommodation → 信任或满意度的因果实验，尤其中文语境。仅得 Reddit 相关性证据（#10）。线索：arXiv:1508.01786（Mimicry Is Presidential, 2015，辩论中 LSM 与民调改善相关）在检索中出现，因预算未取摘要、未计入证据。
- **未找到**：把 judge 分数当 RL reward 后“堆砌特征 / 讨好型冗长 / 表面压缩”的具体 gaming 案例实证；#9 是合成 gold-reward 设定下的 scaling law，#6/#8 只证明谄媚作为偏差源存在。
- **未纳入（预算/篇幅）**：中文检测另有 LLM-Detector（arXiv:2402.01158）与 LoRA 编码器-解码器对比（arXiv:2509.00731），均出现在检索结果中；C-ReD（#4）已覆盖“中文基准”一类，按“同一上游只算一个来源”的精神未重复计入。
- **工具限制（影响覆盖）**：web_search 多查询并发与中文查询多次 60s 超时；web_fetch 被会话检索门控以“上下文已覆盖”为由拒绝。最终证据全部经 arXiv 官方 API（export.arxiv.org）与 Crossref API 在本轮实际取回，摘要为原文，未使用训练记忆补数。
