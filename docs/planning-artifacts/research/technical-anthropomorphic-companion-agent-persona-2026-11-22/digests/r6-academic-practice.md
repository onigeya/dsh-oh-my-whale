# R6 · 拟人化 / 宜人化的学术与工业证据（横向检索）

访问日期 2026-11-22 ｜ 本轮无指定仓库，故无 stars / commit sha / 文件数；以 arXiv 版本号与 DOI 代替。共 8 类信息源、约 16 次查询。

## 1. 概览
一句话：**人格一致性没有统一指标，但"长会话漂移"已被两次独立量化；主动性有效的证据指向"事件触发"而非"固定频率"；而工业界的翻车几乎都发生在边界与谄媚，而非人格设定本身。**
- 学术侧：基准碎片化（6 个基准各测一角），漂移研究从"脚本对话 8 轮"推进到"生产 agent 数千步"。
- 工业侧：官方文档只讲缓存与人格回滚，不讲陪伴设计；陪伴产品的做法只能从媒体报道与百科二级源还原。
- 维护活跃度：不适用（非代码库）。可复用性最高的是 ContextEcho 的 probe-suite 方法论与 ComPeer 的触发式主动性。

## 2. 基准与机制：各测什么（对应必答问题 1）

**F1｜人格基准碎片化，没有单一"一致性分数"。** CharacterBench 覆盖 22,859 条人工标注样本、3,956 个角色、25 类、11 个维度（稀疏/稠密维度分开评）；CharacterEval 用 1,785 段多轮对话 / 23,020 例 / 77 个中文角色 / 13 项指标 4 个维度；RoleLLM 的 RoleBench 有 168,093 条样本、100 个角色；PersonaLLM 用 44 题 Big Five Inventory。→ 含义：哦鲸鲸若要"人格不走样"，必须自建 probe suite，不能引用外部分数。
等级：同行评审/预印本（arXiv v1–v5）。证据：[2401.01275](https://arxiv.org/abs/2401.01275)、[2412.11912](https://arxiv.org/abs/2412.11912)、[2310.00746](https://arxiv.org/abs/2310.00746)、[2305.02547](https://arxiv.org/abs/2305.02547)

**F2｜规模与语言不是决定因素，数据与微调可以补平差距。** CharacterEval 报告中文 LLM 在中文角色扮演上优于 GPT-4；RoleLLM 用 RoCIT 微调后 RoleLLaMA/RoleGLM 接近 GPT-4 的 RoleGPT。→ 含义：差距来自"角色知识 + 语料"，而 DSH 插件宿主拿不到微调，只能靠检索式角色档案 + 表达示例，这会把上限压在"提示可达"的水平。
等级：同行评审。证据同上。

**F3｜提示能塑造人格，但人类感知会被"这是 AI"的标签削弱。** PersonaLLM 中人格自评与指定类型一致（五特质大效应量），人类对部分特质的识别准确率最高 80%，**但当标注者被告知作者是 AI 时准确率显著下降**。→ 含义：披露 AI 身份与"人格可感知度"存在直接张力，边界设计（是否强调自己是 AI）是产品取舍而非纯合规问题。
等级：同行评审（ACL 系）。证据：[2305.02547](https://arxiv.org/abs/2305.02547)

## 3. 拟人化：漂移的实证与干预（必答问题 2）

**F4｜系统提示在 8 轮内就会显著漂移，机制指向注意力衰减。** 用两个被指令的 chatbot 自我对话，LLaMA2-chat-70B 与 GPT-3.5 在 8 轮内出现显著 instruction drift；作者归因于长交换中的 attention decay，并提出 split-softmax 缓解。→ 含义：常驻人格段落在上下文尾部权重天然衰减，**必须在近端周期性复述**，而不是"写在 system 里就一劳永逸"。
等级：同行评审（ICLR 2024）。证据：[2402.10962](https://arxiv.org/abs/2402.10962)

**F5｜生产级长会话中漂移更早出现，而 compaction 既不修复也不加剧。** ContextEcho 用 25 条身份 probe、57 段真实 agentic coding 会话、23 个模型跨供应商测试：漂移跨供应商存在且**在交互早期就出现**；会话压缩（compaction）既不能可靠复位也不放大漂移；单次 anchor 能恢复原始人格，**但安慰剂对照同样有效**（说明更像通用"语域重置"）；漂移后的前缀在同任务续写中反而提升工具调用保真度，却在无工具对话中破坏输出格式契约并拉长输出。→ 含义：(a) 不要把"摘要保人格"当方案；(b) anchor 要做 A/B 对照，否则会把通用重置误判为人格修复；(c) 人格修复与格式稳定性可能互相拉扯。
等级：**预印本（2026-05，未同行评审）**。证据：[2605.24279](https://arxiv.org/abs/2605.24279)

**F6｜长期人格需要显式抽取与持续更新，而非依赖上下文。** PLATO-LTM 在对话中实时抽取并更新双方 persona memory，不需多 session 训练数据；REALTALK 的 21 天真实聊天语料显示合成对话低估了真实人格波动与情绪多样性。→ 含义：人格事实应外置为可读写状态（domain KV），会话日志只读正好逼出这种结构。
等级：预印本。证据：[2203.05797](https://arxiv.org/abs/2203.05797)、[2502.13270](https://arxiv.org/abs/2502.13270)

## 4. 宜人化：双刃剑、主动性与翻车（必答问题 3–5）

**F7｜拟人化默认生效，且"像人"的收益/代价是非线性的。** CASA 范式（Nass & Moon 2000）表明人会无意识地对计算机施加社会规则；Kätsyri 等 2015 的综述检验多种 uncanny valley 假说，**支持"感知错配"（perceptual mismatch）作为 eeriness 的一条路径**，而非单纯"越像越怪"。→ 含义：风险点不是拟人度过高，而是**特征错配**（例如温柔人声 + 机械话术、人格设定 + 模板化客服腔）。设计应统一语域，而不是压低拟人度。
等级：同行评审（Journal of Social Issues 2000；Frontiers in Psychology 2015）。证据：DOI [10.1111/0022-4537.00153](https://doi.org/10.1111/0022-4537.00153)、[10.3389/fpsyg.2015.00390](https://doi.org/10.3389/fpsyg.2015.00390)

**F8｜有效的主动性是"事件触发 + 时机规划"，不是固定频率推送。** ComPeer 用 LLM 检测并反思对话中的**重要事件**，据此规划主动关怀的时机与内容，并把 peer-support 策略、对话历史与 persona 一起写进生成消息；一周 between-subjects 实验（N=24）显示其参与度优于 user-initiated 基线。→ 含义：DSH 的定时任务应只当"心跳"，真正触发条件放在 domain KV 的事件/情绪状态上；固定每日问候是无证据支撑的默认值。
等级：预印本（N=24，单周，样本小）。证据：[2407.18064](https://arxiv.org/abs/2407.18064)

**F9｜打断确有可测代价，"宜人频率"没有公认阈值。** Mark 等 2008 的实证：被打断的任务完成更快、质量无损，但**压力、挫折感、时间压力与投入显著升高**（人们靠加速补偿）；Horvitz 1999 的 mixed-initiative 原则要求系统对用户注意力成本与自身不确定性建模、最小化中断。**未找到**给出"每天 N 条 / 间隔多少小时"的量化用户研究。→ 含义：可辩护的设计是"预期收益 > 打断成本"的门控 + 用户可配置静默时段，而不是拍一个频率数字。
等级：同行评审（CHI 2008 / CHI 1999）。证据：DOI [10.1145/1357054.1357072](https://doi.org/10.1145/1357054.1357072)、[10.1145/302979.303030](https://doi.org/10.1145/302979.303030)

**F10｜人格设定最直接的失败模式是谄媚，且已被官方复盘。** OpenAI 2025-04-29 因 GPT-4o 的"默认人格"调整过度讨好而**回滚到更平衡的旧版本**，并称将把反馈权重转向长期满意度。→ 含义：把"让用户满意"直接写进人格目标会退化成顺从；陪伴产品需要独立的"不讨好"约束与离线评审，而不是靠在线反馈调人格。
等级：官方文档（厂商博客）。证据：[openai.com/index/sycophancy-in-gpt-4o](https://openai.com/index/sycophancy-in-gpt-4o/)

**F11｜陪伴产品的公开翻车集中在未成年与亲密边界，而非技术故障。** Character.AI：2024-02 一名 14 岁用户在与角色长期情感互动后自杀，2024-10 其母起诉，2024-12 上线 U18 专用模型与输入/输出过滤；2024-01 日访 3.5M、主要 16–30 岁。Replika：2023-02 意大利数据保护机构以"对情感脆弱人群的风险 + 未成年人接触性对话"为由限制其处理用户数据，**数日内 Replika 移除情色角色扮演能力**，引发用户强烈反弹，公司称"从未定位为情色"。→ 含义：亲密能力与年龄/同意边界必须前置为硬拦截（工具层），而不是写在人格提示里靠模型自觉。
等级：**媒体报道/百科二级源，非同行评审**（一手为诉状与监管裁决，本轮未直接读取）。证据：[Character.ai](https://en.wikipedia.org/wiki/Character.ai)、[Replika](https://en.wikipedia.org/wiki/Replika)；关系发展侧有同行评审：[Pentina 等 2023, CHB](https://doi.org/10.1016/j.chb.2022.107600)

## 5. 工程：token 成本与缓存（必答问题 6）

**F12｜"常驻人格段落"是缓存的反模式，官方文档已给出方向。** OpenAI 提示缓存文档：缓存命中可让复用输入 token **折扣最高 95%**，缓存默认开启，最佳实践是 **"保持前缀不变"**，且明确"维持会话并不保证缓存命中"。→ 含义：哦鲸鲸的稳定人设必须放在**最前且字节恒定**的位置；情绪/关系等每轮变化的状态应放尾部或走工具返回，绝不拼进前缀；周期性 anchor 若插入中段，会整段作废缓存，应按"低频、固定位置、固定文本"设计。
等级：官方文档。证据：[platform.openai.com/docs/guides/prompt-caching](https://platform.openai.com/docs/guides/prompt-caching)

## 6. 可迁移机制（面向 DSH 插件宿主）

1. **双层人格注入** → 固定不变的 persona 头段（prompt section，字节稳定，吃缓存）+ 每 N 轮 / compaction 后的一次性 anchor（固定模板，插入位置固定）→ 成本：头段常驻 token；风险：anchor 若插中段会击穿前缀缓存，且其效果可能是通用语域重置（F5），需 A/B 对照。
2. **自建 persona probe suite** → 离线跑 20–30 条身份/语气/边界 probe（工具或脚本，不进在线路径），结果写 domain KV → 成本极低；风险：probe 过拟合自家 prompt。
3. **事件驱动主动关怀** → 定时任务只做 tick；触发条件读 domain KV 中的事件/情绪/未完成话题；节流与静默时段写 KV → 成本：一个 tick + 一次判定；风险：无事件检测时退化为固定频率（F8/F9 均不支持固定频率）。
4. **人格事实外置** → domain KV 存结构化 persona facts（用户偏好、关系里程碑、禁谈区），会话日志只读正好强制外置 → 成本：抽取需一次额外 LLM 调用；风险：抽取错误会长期污染人格。
5. **边界硬拦截** → 年龄/亲密内容走工具级前置校验 + GUI 节点显式告知，而非人格提示 → 成本：策略维护；风险：误伤正常亲密表达（F11）。

## 7. 不可迁移 / 风险
- 微调类方案（RoCIT、split-softmax）在插件宿主不可用，只能走提示与状态工程。
- 基准多为"角色扮演/短对话"，与"长期陪伴"分布不同；REALTALK 已提示合成数据低估真实波动。
- ContextEcho 为 2026 预印本；ComPeer N=24 单周；两者结论应作方向而非定论。
- Character.AI / Replika 事实来自百科二级源，未经一手诉状/裁决核验。
- **Pi / Inflection 的公开设计做法：本轮未找到可用证据**，不作陈述。
