- (claim by lead) OWL 2 RL 的全部 Table 4-9 规则 body 均为正向原子，仅 17 条规则 head 为常量 false（eq-diff1/2/3, prp-irp/asyp/pdw/adp/npa1/npa2, cls-nothing2/com/maxc1/maxqc1/maxqc2, cax-dw/adc, dt-not-type）。故 RL 等价于纯正向 Datalog 规则集 + 完整性约束；证伪 = IC 触发，且携带 kernel 可直接供核收缩使用。契约层无需第二个推理器。来源 W3C OWL 2 Profiles REC 2012-12-11 §4.3。
- (claim by lead) OWL 2 RL 的 Table 10 复杂度：一致性检查 taxonomic/data/combined 均为 PTIME-complete；CE-Satisfiability/Subsumption/Instance 的 combined 为 co-NP-complete 但原子类表达式为 PTIME-complete；Conjunctive Query Answering 的 query 与 combined 均为 NP-complete。故契约层查询必须限定为原子类查询（PTIME），多原子 CQ 须拆成原子查询后取交集，禁止运行时构造任意类表达式。来源 W3C OWL 2 Profiles Table 10。
- (claim by lead) Theorem PR1 的代价：对满足 §4.2 句法约束的 RL 本体，规则实现返回 all and only correct answers；对任意 RDF 图则不再保证完备（it is no longer possible to guarantee that all correct answers can be returned），但仍 only produce correct entailments——即 soundness 恒保、completeness 有条件。这印证三值语义中未命中必须标 unknown 而非 false。
